# Technology Stack

## Frontend Technologies
- **Next.js v15.5.3**: React framework with App Router for modern web applications
- **React v19.1.0**: Latest React version with concurrent rendering capabilities
- **Tailwind CSS v4.13**: Utility-first CSS framework for rapid UI development
- **TypeScript**: Strongly typed programming language that builds on JavaScript

## UI Component Libraries
- **shadcn/ui**: Reusable component primitives built with Radix UI and Tailwind CSS
- **Motion**: Animation library for React applications
- **MagicUI**: Collection of beautiful animated components and effects

## AI Services
- **Pollinations.AI API**: Service for AI-generated image and text content

## Development Tools
- **pnpm**: Fast, disk space efficient package manager
- **ESLint**: JavaScript/TypeScript linting utility
- **Context7**: Documentation and code example retrieval tool

## State Management
- **React Context**: Built-in React state management solution
- **React Hooks**: Functionality for managing component state and side effects

## Architecture Patterns
- **React Server Components**: Server-side rendering for improved performance
- **App Router**: File-based routing system in Next.js
- **Component-based Architecture**: Modular, reusable UI components

## Styling Approach
- **Tailwind CSS**: Utility-first styling with shadcn theme integration
- **CSS Variables**: Dynamic theme switching using CSS custom properties
- **Responsive Design**: Mobile-first approach with container queries

## Testing and Quality Assurance
- **Codacy**: Code quality and security analysis platform
- **Playwright**: End-to-end testing framework
